# Anki Automation

**Professional AI-Powered Flashcard Creation for Anki**

Anki Automation is a powerful tool designed to streamline the process of creating high-quality Anki flashcards using Artificial Intelligence. It bridges the gap between your study material and Anki, allowing you to generate, preview, and import rich flashcards with ease.

## Key Features

*   **AI-Driven Content Generation**: Leverage the power of LLMs to automatically generate flashcards from your notes, lectures, transcripts or text.
*   **Rich Formatting Support**: Create cards with Markdown, LaTeX math equations, code blocks, and HTML tables.
*   **Real-Time Preview**: See exactly how your cards will look in Anki before importing them.
*   **Seamless Integration**: Connects directly to Anki Desktop via AnkiConnect for one-click importing.
*   **Professional Templates**: Includes professionally styled card templates with support for dark mode, mobile responsiveness, and interactive elements.
*   **Import History**: Keep track of your generated decks and easily reload previous sessions.

## Download & Installation

### Windows
1.  Download the latest installer from the [Releases](https://github.com/Mik477/Anki-Automation/releases) page or the `installers` folder in this repository.
2.  Run `AnkiAutomation-Setup-1.0.0.exe`.
3.  Follow the installation wizard.
4.  Once installed, the "Getting Started" guide will open automatically to help you set up the connection to Anki.

### MacOS & Linux
*Currently, a native installer is available for Windows only. MacOS and Linux support is planned for future releases.*

## Requirements

*   **Anki Desktop**: You must have the Anki Desktop application installed and running.
*   **AnkiConnect Add-on**: This application requires the AnkiConnect add-on to communicate with Anki.
    *   Add-on Code: `2055492159`
    *   *Detailed setup instructions are provided in the application's Getting Started guide.*

## How It Works

1.  **Launch**: Start the application from your desktop shortcut.
2.  **Create**: Use the provided prompts to guide a LLM of your choosing to generate your flashcard content in YAML format and paste it in the built-in editor.
3.  **Preview**: Verify the look and feel of your cards in the interactive previewer.
4.  **Import**: Click "Import to Anki" to send your new deck directly to your Anki collection.
